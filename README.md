# 伝票スキャン日計（オフライン版）

クレジット売上票をスマホのカメラで撮ると、号車・金額・ブランド・承認番号を読み取り、
号車に登録したドライバーごとに日計・月計を出すアプリです。

- 文字認識はスマホの中で行います（Tesseract.js）。インターネットにもClaudeにも接続しません。
- データはスマホ本体（IndexedDB）に保存します。サーバーには何も送りません。
- 一度開けば、以後は電波がなくても動きます。

## 公開のしかた（GitHub Pages・無料）

アプリを動かすには、一度だけ https のURLから開く必要があります（カメラとオフライン保存の条件）。

1. https://github.com でアカウントを作り、右上の「＋」→「New repository」。
   名前は例えば `slip-scan`。**Private にする場合は有料プランが必要**なので、Public で作ります
   （公開されるのはアプリのプログラムだけで、伝票データはスマホから出ません）。
2. 作ったリポジトリで「Add file」→「Upload files」（空のリポジトリでは、青い枠の中の
   「uploading an existing file」のリンク）。このフォルダの中身
   （`index.html` `app.js` `parser.js` `style.css` `sw.js` `manifest.webmanifest` と
   `icons` `vendor` フォルダ）をまとめてドラッグして「Commit changes」。
3. 「Settings」→「Pages」→ Branch を `main` / `/ (root)` にして「Save」。
   1〜2分後に `https://<ユーザー名>.github.io/slip-scan/` で開けるようになります。

## スマホへのインストール（Android / Chrome）

1. 上のURLをChromeで開き、上部に「文字認識 準備OK（オフライン）」と出るまで待つ（初回のみ約10MBを保存）。
2. メニュー（︙）→「ホーム画面に追加」→「インストール」。
3. 以後はホーム画面のアイコンから開きます。機内モードでも動きます。

## 最初にやること

1. 「設定」→「号車とドライバー」に、号車番号と担当ドライバーを登録。
   スキャン後に未登録の号車があると、設定画面に候補として出ます。
2. 号車番号が読み取れないときは、「読み取りの設定」にレシートで号車番号の前に印字されている言葉を追加。
3. ときどき「バックアップを書き出す」でデータを保存してください（データはスマホの中だけにあります）。

## 更新するとき

ファイルを書き換えたら、`sw.js` の `VERSION`（と `app.js` の `APP_VERSION`）を上げてから
GitHub にアップロードし直します。スマホでアプリを開くと新しい版に切り替わります。
